Crime Alert

Final Year Project

A crime reporting system connecting citizens and security operatives. Citizens report incidents in real time; security operatives receive instant notifications, and nearby residents are automatically alerted through push notifications — closing the gap between an incident happening and people knowing about it.

  • Flutter Web
  • Firebase
  • Push Notifications

Balance

Personal project

A screen-time and digital wellbeing web app for young Nigerians. Instead of draining battery and data with background tracking, it uses quick manual check-ins to build awareness and gives non-judgmental nudges based on how each day compares to your week.
